# The Solo Enterprise charts refuse to render without their required values, so
# several carry render-only placeholders after the pipe. These affect RENDERING
# ONLY -- the real values are passed by the install scripts.

# The *-crds charts contain only CustomResourceDefinitions, so they correctly
# render zero images. derive-images.sh reports that as expected, not a failure.
