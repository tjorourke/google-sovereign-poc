## Scheduling test: a pod requesting 8x nvidia-h100-80gb via the Accelerator compute class
   nodeSelector: cloud.google.com/gke-accelerator=nvidia-h100-80gb
                 cloud.google.com/compute-class=Accelerator
   resources:    nvidia.com/gpu: 8

   Result: Pending indefinitely. Autopilot did not attempt to provision a node.
   84s         Normal    NotTriggerScaleUp   pod/gpuprobe   Pod didn't trigger scale-up: 3 node(s) didn't match Pod's node affinity/selector
   63s         Warning   FailedScheduling    pod/gpuprobe   0/3 nodes are available: 3 node(s) didn't match Pod's node affinity/selector. no new claims to deallocate, preemption: 0/3 nodes are available: 3 Preemption is not helpful for scheduling.

## Conclusion
   The H100 and the a3-edgegpu-8g-nolssd machine type are both advertised, but there is
   no quota bucket for them, so the cluster autoscaler will not even try. GPU inference
   is not available to this project. Note the failure mode is NotTriggerScaleUp rather
   than a quota error, so nothing points at quota as the cause.
